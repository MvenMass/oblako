# Направления — папки `/destinations`

Макет: `docs/design/Cards.dc.html`.

- H1 «Куда отправимся?». Фильтр по региону и настроению (`aria-label="Фильтр направлений"`), стрелки «Предыдущее/Следующее».
- Карусель папок с градиентом `theme.folder` и «ушком» сверху слева. У хитов (`index.hits`) — метка «хит», у остальных папки приглушённые (палитра «Хиты-акцент»).
- Клик по папке — она «открывается»: верх откидывается, выезжает досье (страна, перелёт, виза, сезон, 3 фото) и кнопка «Открыть направление» → `/city/:id`.
- Переход на страницу города — облачный.
