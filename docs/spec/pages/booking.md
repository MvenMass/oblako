# Бронирование `/booking`

Макет: `docs/design/Booking.dc.html`, телефон — `BookingMobile.dc.html`. Бронирование демонстрационное, оплаты нет. Нигде не имитировать настоящую авиакомпанию.

1. **Шаги** (степпер): Рейс → Место → Оплата → Талон.
2. **Схема салона, 20 рядов.** Кнопки мест с `aria-pressed`, легенда.
3. **Вид из иллюминатора** выбранного места:
   - рамка-«стадион», стекло с бликом, шторка (тоггл, анимируется высота);
   - у мест у окна в рядах 7–11 видно крыло;
   - не у окна — размытый вид через салон.
4. **«Терминал печати»** с LED-статусом и кнопкой «Оплатить и получить талон» внутри. По нажатию контейнер талона раскрывается (`max-height 0 → 640`), талон «печатается».
5. **Голографический талон:** наклон за курсором (`rotateX/Y`), перелив `background-position`.
6. **Кошелёк.** Корешок талона улетает вниз (`stubFly`) и появляется в кошельке (`inWallet`).
   - Мобильная версия: стопка из 3 талонов, нажатие достаёт талон, голограмма переливается.
7. После брони в паспорт ставится штамп страны.
