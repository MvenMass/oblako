# Страница города `/city/:id`

Эталоны: `docs/design/CityTbilisi.dc.html`, `CityIstanbul.dc.html` (desktop), `CityTbilisiMobile.dc.html`. Один шаблон, тема — из `city.theme`.

## Секции по порядку

1. **Сцена первого экрана** (780px, отступ 16px, радиус 40px).
   - SVG 1440×780, `preserveAspectRatio="xMidYMax slice"`, слои: небо (3 div с кроссфейдом), звёзды, облака, солнце/луна, дальний, средний, город, вода, передний.
   - Цвета слоёв — через CSS-переменные `--far --mid --city --water --near --win …` из `scene.todPalettes[tod]`.
   - Окна домов: базовый цвет `--winBase` + жёлтый слой с `opacity: var(--win)`.
   - Поверх сцены:
     - чип «страна · регион · IATA» и переключатель «День / Закат / Ночь» (radiogroup);
     - штамп прибытия;
     - H1 `clamp(84px, 13vw, 196px)` и приветствие на местном языке;
     - стеклянная карточка с лидом и кнопками «Собрать маршрут» и «В избранное»;
     - чипы «Сейчас» (Open-Meteo), «Местное время», «Курс» (ЦБ).
   - Тбилиси и Стамбул: взять SVG из макетов и разложить на React-компоненты `Scene/<City>.tsx`.
   - Остальные 9 городов: нарисовать сцену по `scene.description` в той же технике (простые формы, 4 слоя, одна живая деталь).
   - Палитры: день — светлое небо, закат — розово-лиловое, ночь — `#06172F`. Ориентир — `todPalettes` Тбилиси.
   - Время суток по умолчанию: закат для Тбилиси, день для остальных. Можно ставить по реальному местному времени.
2. **«Коротко о главном»** — бенто фактов: перелёт, виза, язык, разница во времени, сезон, розетки, валюта.
3. **«Куда сходить» — галерея.**
   - Фильтр-чипы: Всё / Смотреть / Есть / Природа / Вечером. Категории без мест не показываются.
   - Стопка: активная карточка 76% ширины; позиции `+1`: `translateX(15%) scale(.9) rotate(2.5deg)`, `+2`: `27% .8 5deg`, ушедшая `−1`: `−24% .94 −6deg`, opacity 0.
   - Ken Burns на активном фото, полоска прогресса 5,2 с, автоплей.
   - Правая колонка: категория, счётчик «03 / 08», название, описание, район / время / цена, кнопка «В маршрут» (тоггл, сохраняется в `routeAdded`), стрелки.
   - Мини-карта 440×300 с точками мест, активная пульсирует, клик по точке открывает место.
   - Подпись «Фото: Pexels · цены ориентировочные».
4. **«Что нужно знать»** — 4 карточки `know` с иконками.
5. **«Советуем»** — карта района с табами по категориям мест и списком.
6. **«Попробовать»** — 4 карточки `dishes`, переворачиваются по клику (фронт — название и тон, оборот — описание).
7. **«Разговорник»** — сетка 6 фраз: местная письменность (`lang`), транскрипция цветом акцента, перевод. Клик — озвучка, эквалайзер. Не рендерить, если `phrases.items` пуст.
8. **«Цены против Москвы»** — 5 строк, две полосы (город — `accent`, Москва — `#B9C6D3`), значения в ₽ и местной валюте. Карточка «в среднем на N% дешевле/дороже». Курс — живой ЦБ или демо.
9. **«Сезоны»** — столбики `climate.avgHighC` по месяцам, лучшие месяцы — градиентом `accent2 → accent`.
10. **«3 дня»** (`#plan`) — таймлайн `itinerary`, кнопка «Открыть в конструкторе маршрута».

## Состояния

- Пока данные грузятся — скелетоны (стеклянные плашки с шиммером).
- Неизвестный `:id` — страница 404 «Такого облака нет».
