# Дневник `/journal`

Макет: `docs/design/Journal.dc.html`.

- **«Год назад вы были в Тбилиси»** — воспоминание сверху.
- **«Стол с фотографиями»:**
  - полароиды (подписи шрифтом Caveat) перетаскиваются по столу (Draggable с инерцией);
  - кнопки «Предыдущее/Следующее фото»;
  - фильтр поездок.
- **Сторис поездки:** оверлей, полоски прогресса, тап-зоны.
- **«Маршрут по фото».** Карта, точки соединены линией в порядке съёмки. Линия перерисовывается при смене поездки.
- **Данные:** поездки из store; фото пользователя — `<input type="file">`, хранение в IndexedDB (idb-keyval). Демо-поездка — из фото Тбилиси.
