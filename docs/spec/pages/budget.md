# Бюджет поездки `/budget`

Макет: `docs/design/Data.dc.html` — бенто разного размера.

- **«Деньги под контролем».** Плитки:
  - накопленные траты по дням (линия);
  - кольцо категорий: перелёт, жильё, еда, впечатления;
  - прогресс «накоплено N%»;
  - курс валюты (ЦБ);
  - мини-маршрут;
  - самая дорогая и самая дешёвая трата.
- Траты вводит пользователь (форма «+ трата»: сумма, валюта, категория, день). Конвертация по курсу ЦБ.
- Все демо-графики подписаны `aria-label` с цифрами.
