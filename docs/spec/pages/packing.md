# Сборы `/packing`

Макет: `docs/design/Packing.dc.html` (раскладка вещей), телефон — `PackingMobile.dc.html`.

- **Сцена 1232×720, «льняной пол».**
  - Открытый чемодан сверху: крышка с сеткой-карманом, золотая молния, ручка, колёса.
  - Ремни застёгиваются, когда уложено больше 6 вещей.
- **15 вещей-иллюстраций** (SVG, см. макет): паспорт, страховка, карта, зарядка, пауэрбанк, наушники, щётка, крем SPF, футболки, куртка, брюки, платок, обувь, аптечка (розовый плюс, не красный крест), зонт.
  - Каждая вещь — `<button aria-pressed>`.
  - Клик — полёт по дуге в слот (`left` 0,85 с `cubic-bezier(.45,0,.25,1)`, `top` с `cubic-bezier(.3,-0.55,.4,1.1)`, поворот и `scale .72`).
  - Документы и техника летят в сетку крышки, одежда — в корпус. Повторный клик возвращает вещь на пол.
- **Бейдж «совет»** у вещей из погоды и культуры города (крем, куртка, брюки, платок, зонт). Правила — по городу и прогнозу Open-Meteo.
- **Багажная бирка.** Вес: база 3,2 кг + вещи; ближе к лимиту (>21 из 23 кг) бирка розовеет.
- **Шапка:** прогресс «Уложено N из 15», «Собрать всё», «Вытряхнуть», полоса погоды на 7 дней (дождь анимирован).
- **Доступность:** блок «Списком» (`<details>`) с чекбоксами (`role="checkbox"`).
- **Финал:** конфетти, когда собрано всё.
- **Мобильная версия:** чемодан сверху, полка вещей с горизонтальным скроллом, вещь «прыгает» в слот.
