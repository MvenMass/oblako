# Служебные состояния

- **404 «Такого облака нет».** Сияние, одно облако с грустным лицом-иконкой (без эмодзи), кнопки «На главную» и «Подобрать поездку». Заголовок с `.grad`.
- **Пустые состояния:**
  - маршрут: «Маршрут пока пуст — добавьте места из галереи города или пройдите подбор»;
  - дневник: «Добавьте первые фото»;
  - сборы без поездки: «Сначала выберите направление»;
  - паспорт без штампов: «Штампы появятся после первой брони».

  У каждого пустого состояния — иллюстрация в стиле сайта (стекло, облако) и одна CTA.
- **Ошибки API.** Тихие: чип с «—» и подсказкой, без красных баннеров.
- **Офлайн.** Плашка «Нет сети: показываем сохранённые данные».
