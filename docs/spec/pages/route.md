# Конструктор маршрута `/route`

Макет: `docs/design/Route.dc.html`, телефон — `RouteMobile.dc.html`.

- **Карта.** Наклонная 3D-карта дня: `perspective` и `rotateX(38–50deg)`, выдавленные кварталы, река.
  - Метки точек стоят вертикально — компенсируют наклон.
  - Линия маршрута рисуется `stroke-dashoffset`.
  - Табы дней (`role="tablist"`).
- **Список точек справа:**
  - перетаскивание меняет порядок — GSAP Draggable + Flip, абсолютное позиционирование с transition;
  - клавиатура: фокус на точке, `Alt+↑/↓` — переместить;
  - время в пути между точками пересчитывается.
- **Циферблат дня 24 ч.** SVG-кольцо, сектора — время на точках, стрелка — текущее время.
- **Источник точек:** результат квиза, кнопка «В маршрут» из галереи города, ручное добавление из списка `places`.
- **Мобильная версия:** карта сверху, снизу выдвижная панель (bottom sheet, ручка `aria-expanded`), табы дней, список, итог «пешком / точек / погода».
