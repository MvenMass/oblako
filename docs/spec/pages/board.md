# Табло вылетов `/board`

Макет: `docs/design/Board.dc.html` (тёмная тема), телефон — `BoardMobile.dc.html`.

- **Перекидное табло.** Строки рейсов (время, направление, рейс, выход, статус).
  - Буквы — флипы `flipA/flipB` (`rotateX(-90deg → 0)`, 0,12 с), пробегают случайные буквы.
  - Каждые ~4 с один статус меняется: Посадка / По плану / Задержан / Регистрация / Вылетел; «Посадка» мигает.
- **Звук щелчков.** Web Audio (короткий шум с огибающей). Тоггл, по умолчанию выключен, состояние в store.
- **Радар.** Конический sweep 4 с, блипы затухают.
- **Пролёт.** Самолёт пересекает экран раз в 60 с.
- **«Слежу за рейсом».** Схема полёта Москва — город с прогрессом.
- Данные рейсов — демо-генератор от городов из JSON. Подписать «демо-табло».
