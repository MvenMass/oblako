# Дизайн-токены OBLAKO

Источник правды — макеты в `docs/design/*.dc.html` (стили инлайном) и этот файл. В коде токены живут в `src/styles/tokens.css` как CSS-переменные.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `--ink` | `#0B2540` | основной текст |
| `--muted` | `#3A5269` | вторичный текст; затемнён с `#45607A`, чтобы держать 4,5:1 на розовом и голубом сиянии |
| `--sky-ink` | `#044A68` | бирюзовый мелкий текст (надзаголовки, ссылки) — 4,5:1 даже на сиянии |
| `--bg` | `#F4FAFE` | фон страниц |
| `--sky-deep` | `#0A79A8` | надзаголовки, ссылки |
| `--sky` | `#38BDE8` | акцент, начало градиентов |
| `--morning` | `#E3F6FD` | подложки, лёгкие плашки |
| `--pink` | `#C8146F` | **кнопки CTA** (контраст с белым 5,6:1) |
| `--flamingo` | `#E8288E` | декоративный розовый (не для текста на белом) |
| `--dusk` | `#8B6CF0` | лиловый, третий цвет градиентов |
| `--night` | `#06172F` | тёмная тема (Табло), футер |
| `--success` | `#3FB98C` / текст `#1F6B4D` | «укладываетесь», «в маршруте» |

Логотип: облако с градиентом `#BDEBFA → #38BDE8 → #0A79A8` + слово **OBLAKO** (латиница, 800, трекинг 0.04em).

Градиенты:
- живой градиент акцентных слов `.grad`: `linear-gradient(90deg,#0A79A8,#E8288E 33%,#8B6CF0 66%,#0A79A8)`, `background-size:300% 100%`, анимация `shift 8s linear infinite` (позиция → `300% 0`);
- полоски прогресса: `linear-gradient(90deg,#38BDE8,#E8288E)`;
- у каждого города своя тема (`theme` в JSON): `accent`, `accent2`, `folder[2]`, `bg`, `ink`, `muted`, у Тбилиси и Стамбула ещё `gradient`.

## Шрифт

- **Onest** (Google Fonts), веса 400/500/600/700/800. Никаких засечек (Playfair отклонён).
- Дополнительно: `Caveat 600` — подписи полароидов; `IBM Plex Mono 500` — табло; `Noto Serif Georgian 500/700` — грузинская письменность. Для других письменностей (армянская, китайская) — системные шрифты, отдельный webfont не нужен.
- Шкала заголовков (desktop → mobile): H1 героя 88–96 → 44; H1 страниц 56 → 38; H2 секций 56 → 34; H2 внутри страниц 44 → 30; лид 18–19; текст 15–17; подписи 12–13.
- Межбуквенный у крупных заголовков: `-0.04em … -0.06em`; надзаголовки: 13px, 700, uppercase, `0.14em`, цвет `--sky-deep`.

## Радиусы

| Элемент | Радиус |
|---|---|
| Кнопки, инпуты, чипы | **14px** (пилюли не используем) |
| Мелкие чипы и бейджи | 8–12px |
| Карточки | 22–28px |
| Крупные панели, сцены | 32–40px |
| Папки | `6px 18px 18px 18px` + «ушко» сверху слева |

Минимальная высота интерактивных элементов — 44px, у основных кнопок 52–56px.

## Liquid glass (`.lg`)

```css
background: rgba(255,255,255,.42);
backdrop-filter: blur(24px) saturate(180%);
-webkit-backdrop-filter: blur(24px) saturate(180%);
border: 1px solid rgba(255,255,255,.7);
box-shadow: inset 0 1px 0 rgba(255,255,255,.95), 0 24px 60px rgba(11,37,64,.1);
```
Тёмный вариант (`.lgd`): фон `rgba(255,255,255,.07)`, бордер `.14`, блик `.18`.
Фолбэк без `backdrop-filter` (`@supports not`): фон `rgba(255,255,255,.85)`.

## Фон: северное сияние и облака

- `.aur` — 2–3 размытых круга 560–680px, `filter: blur(80px)`, анимация `aur 22s` (сдвиг ±50px, scale 0.92–1.15). Цвета по умолчанию `#9BDDF2`, `#FFB3D6`, `#C3B5FF`; на странице города — `theme.aurora`, в квизе — по выбранному настроению.
- Облака — SVG-эллипсы белые, `feGaussianBlur` 12–30, анимация `sail 40s` (дрейф на 80px).
- Шум/зерно на главной — SVG `feTurbulence` с opacity .05.

## Тени

- Карточки: `0 14px 34px rgba(11,37,64,.08)`; поднятая: `0 24px 50px rgba(11,37,64,.18)`.
- Розовая CTA: `0 14px 34px rgba(200,20,111,.32)`.

## Сетка

Контейнер `max-width: 1280px`, паддинги 24px (16px на мобильном). Карточки — `grid-template-columns: repeat(auto-fill/auto-fit, minmax(240–280px, 1fr))`. Брейкпоинты: 1024, 768, 480.
