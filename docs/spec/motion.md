# Анимации OBLAKO

Инструменты: **GSAP 3** (ScrollTrigger, Draggable, Flip — бесплатны), **Lenis** для плавного скролла, CSS-анимации для бесконечных декоративных эффектов, Canvas 2D для глобуса и сферы-облака.

## Общие правила

1. Хук `usePrefersReducedMotion()`. При `reduce`:
   - бесконечные анимации (сияние, облака, мерцание, градиент текста) выключаются;
   - переходы схлопываются до ≤150 мс или до мгновенной смены состояния;
   - автопрокрутки и автоплеи не запускаются;
   - элементы, появляющиеся через анимацию (штампы, «пустые» состояния), сразу видимы.
2. Анимируем только `transform` и `opacity` (кроме оговорённых `width` у прогресса и `clip-path` у сравнения).
3. Бесконечные циклы и rAF-петли ставятся на паузу, когда секция вне экрана (IntersectionObserver), и при `document.hidden`.
4. Кривые: вход `cubic-bezier(.2,.8,.2,1)`; «пружина» `cubic-bezier(.3,1.3,.4,1)`; дуга полёта по Y `cubic-bezier(.3,-0.55,.4,1.1)`.

## Глобальные

| Эффект | Параметры |
|---|---|
| Облачный переход между страницами | Две стены облаков (`enterL`/`enterR`) расходятся за 1,1 с при монтировании страницы. GSAP-таймлайн в `PageTransition`. |
| `.rise` | Появление: `translateY(20px) → 0`, opacity 0 → 1, 0,7 с, задержки по 0,08–0,1 с. ScrollTrigger `start: 'top 85%'`, один раз. |
| Градиент текста | `shift 8s linear infinite`. |
| Северное сияние на главной | Реагирует на мышь: смещение до ±40px с инерцией (lerp 0,08). |

## Главная

- **Глобус** (Canvas 2D, ретина, точечная маска суши 144×72): авто-вращение 0,0025 рад/кадр, перетаскивание (pointer capture), 11 дуг Москва → город с бегущими точками, пинги городов.
- **Как работает:**
  - путь SVG, самолётик едет по `getPointAtLength`;
  - со ScrollTrigger: pin секции и `scrub: 0.5`, прогресс 0 → 1;
  - без прокрутки (короткий экран) — автоплей 11 с по кругу;
  - мини-карточки на остановках: opacity + `translateY(14px) scale(.85) → none`, пружина 0,6 с;
  - приборы: стрелка `rotate(-90deg → значение)` 1,8 с, пружина, задержка 0,15 с на каждый;
  - счётчик цифр через `gsap.to({v})`.
- **Облако настроений.** Сфера Фибоначчи, 22 тега, R = 230.
  - Вращение: `ay += dt·(0,28 + mouseX·1,2)`, наклон `ax` тянется к `mouseY·0,8 − 0,25`.
  - Обновление ≤ 30 fps, только в зоне видимости.
  - Глубина влияет на размер шрифта 14–24px, scale 0,7–1,15, opacity 0,28–1 и z-index.
- **Сравнение городов.** `clip-path: inset(0 X% 0 0)` у верхнего слоя, ручка тянется мышью и стрелками. Отпускание — easing 0,5 с.
- **Истории.**
  - Coverflow: `translateX(d·250px) translateZ(-|d|·160px) rotateY(∓38deg)`, 0,7 с.
  - Сторис: полоски прогресса по 3,2 с, текст `txt` (снизу вверх, 0,5 с), фото с Ken Burns `scale 1.02 → 1.14` за 9 с.
- **FAQ-чат:**
  - сообщение влетает `msgIn` (`translateY(10px) scale(.96)`, 0,35 с);
  - «печатает…» — три точки по 1 с с задержками 0,15 с;
  - ответ приходит через 1,1 с;
  - после каждого сообщения — автоскролл вниз.
- **Талон.** Корешок тянется вправо (pointer events). При смещении больше 110px он отрывается: `translate(240px,160px) rotate(28deg)`, opacity 0 за 0,9 с. Основная часть билета коротко трясётся (`shake` 0,5 с), появляется CTA (`popIn`).

## Страница города

- **Сцена.** 4 слоя параллакса со сдвигом при движении мыши: дальний 8px, средний 18, город 30, передний 56. Transition 0,8 с.
- **День / закат / ночь.** Смена CSS-переменных палитры с `transition: fill 1.2s`. Небо — три слоя с кроссфейдом opacity 1,2 с. Солнце или луна переезжают за 1,4 с.
- **Штамп** «прилетает» через 1,1 с: `scale 2.4 rotate(-34deg) → scale 1 rotate(-14deg)`, 0,6 с.
- **Живые детали:** кабинка канатки 22 с туда-обратно, паром 26 с, чайки, качание ламп 5 с, мерцание огней 3 с.
- **Галерея:**
  - стопка карточек с позициями `0 / +1 / +2 / −1` (см. `pages/city.md`), переход 0,8 с;
  - автоплей 5,2 с с полоской прогресса, пауза при наведении и фокусе;
  - Ken Burns на активном фото;
  - свайп от 50px, стрелки ← →.
- **Цены.** Полосы растут по ширине за 1,2 с при входе в экран, задержка 0,1 с на строку.
- **Разговорник.** Во время озвучки — эквалайзер из трёх полосок (`scaleY .4 ↔ 1`, 0,6 с).
