# Макеты

`.dc.html` — снимки макетов с доски дизайна: HTML + CSS + небольшой JS. В них уже работают все интерактивы — переходы квиза, галерея, укладка вещей, табло. Открывать в браузере как есть.

**Фото в макетах не грузятся локально.** Ссылки вида `/_blob/…` работали только на доске. Настоящие фото лежат в `public/photos/<city>/` — в коде берите их оттуда.

Макеты — эталон вида и поведения, а не код для копирования: в них инлайн-стили и технические атрибуты доски (`sc-for`, `sc-if`, `{{…}}`). Переносите в React-компоненты по правилам проекта (CSS Modules, токены, доступность — см. `docs/spec/`).
